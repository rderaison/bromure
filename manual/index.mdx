# Bromure Agentic Coding — User Manual

Welcome to the official user manual for **Bromure Agentic Coding**, the macOS app that runs AI coding agents — Claude Code, Codex, Grok, Kimi Code, Oh My Pi, and ordinary shell tooling — inside isolated Linux virtual machines on your Mac, with a host-side gateway that keeps your real credentials out of the agent's reach.

This manual documents version **5.0.0**. It requires macOS 14 (Sonoma) or later on Apple Silicon.

Version 5.0.0 is organized around **sessions**: each conversation with an agent is a row in the sidebar, and you talk to it in a chat. The Linux VMs that sessions run in are called **machines** in the main window. The settings editor still calls them **workspaces**; the two words mean the same thing.

> **New to the app?** Start with [Installation & First Run](02-installation.mdx), then follow the [Quick Start](03-quick-start.mdx). Read [Concepts & Architecture](04-concepts.mdx) when you want the full picture. Use everything else as reference.

## Conventions used in this manual

- **Bold** text names an on-screen control or label exactly as the app shows it in English — a button, menu item, toggle, pane, or sidebar section (for example, **New session** or **Start this VM at login**).
- `Monospace` text is a command, file path, environment variable, or literal value you type or see (for example, `bromure-cli vm ls` or `~/Library/Application Support/BromureAC`).
- A path such as **Workspaces › Infrastructure › Messaging Connector…** is a menu path: the menu, then each submenu or item in order. **Preferences › Models** means the Models pane of the Preferences window.
- **Machine** and **workspace** mean the same thing: one isolated Linux VM with its settings. The main window says *machine*; the settings editor, menus such as **New Workspace…**, and the CLI say *workspace* (or *profile*).
- A **session** is one conversation with an agent, in one folder, on one machine. It is not a run of a machine; see [Concepts & Architecture](04-concepts.mdx).
- Keyboard shortcuts use the macOS symbols: ⌘ Command, ⌥ Option, ⌃ Control, ⇧ Shift, ⏎ Return, ⎋ Escape.
- Screenshots show the English interface with synthetic demo content. The app is localized, so your screens follow your macOS language.
- Notes, tips, and warnings appear as callouts:

> **Note:** Background information worth knowing.

> **Tip:** A shortcut or recommended practice.

> **Warning:** Something that can lose data or weaken a protection if you get it wrong.
