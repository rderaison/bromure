# Bromure — User Manual

Welcome to the official user manual for **Bromure**, the macOS web browser that runs every window inside its own disposable Linux virtual machine. Web pages never run on your Mac: each window gets a fresh VM, started from a clean image, and closing the window destroys it along with everything it touched. When you want a browser that remembers your sign-ins, a persistent profile keeps just your browsing data on a separate, optionally encrypted disk.

This manual documents version **5.0.0**. It requires macOS 14 (Sonoma) or later on Apple Silicon.

> **New to Bromure?** Start with [Installation & First Run](02-installation.mdx), then follow the [Quick Start](03-quick-start.mdx). Read [Concepts & Architecture](04-concepts.mdx) when you want the full picture. Use everything else as reference.

## Conventions used in this manual

- **Bold** text names an on-screen control or label exactly as the app shows it in English — a button, menu item, toggle, category or pane (for example, **New Private Window** or **Retain Browsing Data**).
- `Monospace` text is a command, file path, defaults key, port or literal value (for example, `~/Library/Application Support/Bromure` or `automation.port`).
- A path such as **File › New Window With Profile** is a menu path: the menu, then each submenu or item in order. **Settings › Network** means the Network pane of the Settings window; a profile's **General** category means that category of the profile's settings window.
- A **window** and a **session** are the same thing seen from two sides: one browser window and the Linux VM behind it. Menus and alerts often say *browser session*.
- Keyboard shortcuts use the macOS symbols: ⌘ Command, ⌥ Option, ⌃ Control, ⇧ Shift, ⏎ Return, ⎋ Escape.
- Screenshots show the English interface with a demo profile named **Work**. The app is localized, so your screens follow your macOS language.
- Notes, tips, and warnings appear as callouts:

> **Note:** Background information worth knowing.

> **Tip:** A shortcut or recommended practice.

> **Warning:** Something that can lose data or weaken a protection if you get it wrong.
