# General

The **General** pane ("App-wide preferences") holds two settings: which profile Bromure opens when it needs a new window and none is in front, and which profile opens web links that you click outside Bromure.

## Settings

| Setting | Description |
|---|---|
| **Open New Windows With** | "The profile Bromure opens when you launch it, click its Dock icon, or press ⌘N with no browser window in front." The menu lists **Last Used Profile** followed by every profile. Default: **Last Used Profile**. |
| **Default Profile for Links** | "When Bromure is your default browser, links clicked in other apps open with this profile. Choose “Ask Every Time” to pick a profile on each click." The menu lists **Ask Every Time** followed by every profile. Default: **Ask Every Time**. |

## Open New Windows With

Bromure opens a window of this profile whenever it needs a window and none is in front:

- when you launch Bromure;
- when you click its Dock icon with no window open;
- when you press ⌘N (**File › New Window**) with no browser window in front. With a window in front, ⌘N opens another window of *that* window's profile.

**Last Used Profile** (the default) opens the profile you used most recently, so the choice follows whatever you browsed with last. Pick a profile to always start there instead — for example your **Work** profile, or **Private Browsing** if you'd rather every fresh start keep nothing.

You can also set it from any window: open the profile chip at the left of the tab bar and choose **Open New Windows with “*name*”**. The item is checked while that window's profile is the one new windows open with; choose it again to go back to **Last Used Profile**. Both places change the same setting.

If you delete the chosen profile, Bromure goes back to **Last Used Profile**.

## How a link is routed

When another app hands Bromure an `http` or `https` link:

- **With a default profile chosen**, the link goes straight to that profile. If a window of that profile is already open, the link opens in it; otherwise Bromure opens a new window of that profile on the link.
- **With Ask Every Time**, Bromure shows **Choose where to open this link** whenever there is more than one possible destination. The menu lists your profiles and, under **Other browsers**, the other web browsers installed on your Mac, so you can send a link you don't want to open in a VM to Safari or another browser. Click **Open**, or **Cancel** to drop the link.
- **With a single profile and no other browser installed**, there is nothing to choose: the link opens in the active window, or in a new window of that profile.

If the profile you picked as default is later deleted, Bromure falls back to the **Ask Every Time** behavior. If Bromure is still setting up or rebuilding its image when a link arrives, the link is kept and opened once the image is ready.

To make Bromure your default browser, use **System Settings › Desktop & Dock › Default web browser**.

## Preferences keys

| Setting | Key | Type | Default |
|---|---|---|---|
| **Open New Windows With** | `launch.defaultProfileID` | String (a profile UUID; empty means Last Used Profile) | empty |
| **Default Profile for Links** | `links.defaultProfileID` | String (a profile UUID; empty means Ask Every Time) | empty |
